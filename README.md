# ШКАФ — образы из ваших вещей

Личный стилист в браузере: вы фотографируете одежду — приложение собирает образы **из реальных вещей в шкафу**
по погоде, поводу и палитре сезона. Фото никуда не загружаются, шкаф хранится в браузере (IndexedDB).
Работает на телефоне и ноутбуке, ставится на домашний экран как приложение (PWA).

## Установить на экран

### Ссылки

| Где | Ссылка |
|---|---|
| **Телефон / планшет (постоянная HTTPS)** | **https://vavkaiser-web.github.io/shkaf/** |
| Резерв (туннель, временный) | https://revolutionary-cell-interior-administrator.trycloudflare.com/ |
| Ноутбук (этот Mac) | http://127.0.0.1:8765/ |
| Телефон по Wi-Fi (без HTTPS) | http://192.168.2.140:8765/ |

Основная ссылка — **GitHub Pages**: постоянная, с HTTPS, не зависит от этого компьютера и туннеля.
С неё приложение нормально устанавливается на Android и iPhone. После установки открывается с иконки и работает
из офлайн-кэша; шкаф и фото остаются в памяти браузера.

Резервная ссылка (Cloudflare Tunnel) нужна, только если GitHub Pages недоступен с вашей сети;
она временная и меняется при перезапуске (`./share.command`).

### Как установить

**Android (Chrome):** откройте ссылку → баннер «Установить» или кнопка в шапке (стрелка вниз) →
системное окно «Установить приложение» → «Установить». Иконка появится на главном экране.
Если системного окна нет: меню Chrome ⋮ → «Установить приложение» / «Добавить на главный экран».

**iPhone / iPad (Safari):** откройте HTTPS-ссылку **в Safari** (не в Chrome и не в Instagram) → кнопка «Поделиться»
(квадрат со стрелкой) → «На экран «Домой»» → «Добавить». Запускайте с иконки — откроется без адресной строки.

**Mac (Chrome/Edge):** откройте http://127.0.0.1:8765/ → иконка установки в адресной строке (справа)
или кнопка-стрелка в шапке приложения → «Установить». В Safari: «Файл» → «Добавить в Dock».

Внутри приложения: кнопка-стрелка в шапке, баннер «Установите «ШКАФ» на экран» или
«Настройки → Установка» — там QR-код, ссылка, копирование и пошаговая инструкция под ваш телефон.

### Как обновить постоянную ссылку (GitHub Pages)

Исходники лежат в репозитории [vavkaiser-web/shkaf](https://github.com/vavkaiser-web/shkaf), сайт — ветка `main`, корень.
Любой коммит в `main` автоматически пересобирает страницу:

```bash
cd wardrobe
git add -A && git commit -m "обновление" && git push
```

### Резервная HTTPS-ссылка (туннель) заново

Нужна для установки на Android и для открытия с телефона вне Wi-Fi. Туннель поднимается так:

```bash
cd wardrobe
./share.command        # поднимет сервер (если нужно) и временную HTTPS-ссылку
```

Скрипт напишет ссылку и сохранит её в `.public-url`; приложение само подставит её в QR-код.
Туннель работает, пока открыто окно скрипта. Под капотом — Cloudflare Quick Tunnel (без аккаунта).

Если бинарника нет (после переустановки/переноса папки):

```bash
mkdir -p .tools && cd .tools
curl -L -o cloudflared.tgz https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-darwin-arm64.tgz
tar -xzf cloudflared.tgz && chmod +x cloudflared
```

### Локально без публичной ссылки

```bash
cd wardrobe
./start.command     # сервер + браузер
# или
npm run serve       # python3 serve.py 8765
```

> Не открывайте через `file://`: Safari не даст сохранять фото. Установка PWA работает на `localhost`,
> а на Android — только по HTTPS (поэтому и нужна публичная ссылка). На iPhone «На экран «Домой»» работает и по Wi-Fi,
> но без офлайн-кэша.

## Как пользоваться

1. **Добавьте вещи:** «＋» → фото с камеры/галереи. Цвет и палитра вытягиваются из фото автоматически,
   категорию/теплоту/формальность выбираете в пару кликов.
2. **Демо-шкаф** (кнопка на пустом экране) — 20 вещей в палитре сезона: можно сразу увидеть логику.
3. **Погода:** по умолчанию Берлин; в настройках — поиск города или «Моё местоположение». Без интернета — «Погода → Вручную».
4. **Соберите образы:** выберите повод (Будни / Работа / Вечер / Спорт) → «Собрать образ».
   «Ещё варианты» — другая подборка без повторов недавнего, «×» — больше не предлагать.
5. **Надевайте и сохраняйте:** «Надеть» пишет носку, закладка сохраняет образ в «Мои образы».
   «Стиль» — палитра сезона, сочетания и статистика «пора надеть».

### Что учитывает движок

- **Погода:** температура и «ощущается», дождь/снег, ветер. Дождь → водоотталкивающие верх и обувь; мороз → без шорт/сандалий;
  жара → без пуховиков и сапог.
- **Сезон 2026/27:** бордо, вишня, слива, шоколад, ивори, синий ночи, олива, горчица, терракота + 9 рабочих сочетаний.
  Источники: [Pantone A/W 2026/27](https://www.pantone.com/eu/en-de/articles/fashion-color-trend-report/new-york-fashion-week-autumn-winter-2026),
  [Vogue UA](https://vogue.ua/article/fashion/tendencii/slivoviy-chervoniy-i-girchichniy-6-naymodnishih-koloriv-holodnogo-sezonu-65421.html),
  [Rinascimento](https://magazine.rinascimento.com/es-es/blog/paleta-de-colores-rinascimento-otono-invierno),
  [Vogue France](https://www.vogue.fr/article/combos-couleurs-automne-hiver-2026-2027).
  Весна/лето 2027 — прогноз.
- **Повод:** формальность и стилевые теги.
- **Новизна:** штраф за недавно ношенное/повтор, бонус забытым вещам, 6 разных образов без вариаций.
- **Только ваши вещи:** ничего не выдумывается, всё берётся из шкафа.

## Данные и приватность

- Вещи, фото, образы, история — только в этом браузере (IndexedDB; fallback localStorage/память).
- Наружу уходят только запросы погоды на Open-Meteo. Фото не загружаются никуда.
- Локальный сервер и туннель отдают только файлы приложения (allowlist): без тестов, node_modules и служебных файлов.
- GitHub Pages отдаёт код приложения публично (без ваших вещей и фото — они хранятся в браузере).
  Чужой человек по ссылке увидит пустой шкаф — данные хранятся в его браузере, а не на сервере.
- Настройки → «Данные»: экспорт/импорт JSON-копии, очистка. Чистка браузера удалит шкаф — делайте копию.

## Ограничения

- Установка на Android требует HTTPS — для этого и нужен временный туннель. Для постоянной ссылки лучше
  задеплоить статику на GitHub Pages / Netlify / Cloudflare Pages (аккаунт нужен).
- GitHub Pages: ссылка постоянная; репозиторий публичный (код приложения, без данных).
- Туннель — резервный, временный: меняется при перезапуске.
- Категорию/теплоту вещи выбираете вы; цвет и палитра — автоматически.
- Демо-фото — SVG-силуэты, не чужие фотографии.
- Оценка образа — прозрачная эвристика (цвет + формальность + тренд + новизна), а не вкус стилиста.
